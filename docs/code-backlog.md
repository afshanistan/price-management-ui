## Global
- **Motion standard** · all components · 150ms ease-out on every state change; no springs on color. · Figma's Smart Animate unsnaps pixels mid-transition (1px shifts); resting states are correct.
- **Press scale on buttons** · Button, Icon button · `transform: scale(0.97)` on press. · Figma can't do it cleanly.
- **Reduced motion** · everything that moves · all scale/draw/slide effects off under `prefers-reduced-motion`.
- **Icon color = `currentColor`** · Icon, Pictogram · drop the Semantic/Icon modes; icons inherit the text color of their container. · The modes are a Figma-only stand-in (Figma drops color overrides on icon swap).
- **Focus ring = `outline`** · all interactive components · `outline` + `outline-offset`, not an extra element. · Figma uses a "Focus ring" frame. **Exception (Oct 18): text fields** show focus as their own border going 2px teal (`--border-input-focus`), no ring around it; forced colors fall back to a 2px system outline.
- **Containers declare context** · Main navigation, Group header (Strong) · `data-mode="on-brand"` on the container redefines the CSS variables; children never set a color mode. Nested opt-outs (e.g. the logo tile in the Group header) reset to light.
- **Status tokens** · CountBadge, StatusMark, VendorCoverage (and later Stepper) · `--fill-status-todo / --text-on-status-todo`, `--fill-status-complete / --text-on-status-complete`, `--icon-on-status-complete`, `--border-status-todo` (dashed ring). In-progress pair still to design with the stepper. Citron is never interactive and never text color; always pair with a number or check.
- **Search clear button** · Input (Filled state) — used by Select vendors and Select brands · a `<button aria-label="Clear search">` with the Close icon at the end of the field, shown only when the field has text; clears the query, keeps focus in the input. Esc also clears. (Added Oct 17; target and hover in the Accessibility section.)
